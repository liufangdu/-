# 猜数字游戏

一个使用 Python 编写的命令行小游戏。程序会随机生成一个 1 到 100 之间的整数，玩家通过输入数字来猜答案；程序会根据每次猜测提示“大了”或“小了”，直到猜中为止，并统计猜中的次数。

## 功能

- 每局随机生成 1–100 的答案，每次运行都不一样
- 输入过大或过小时给出提示
- 自动校验输入：
  - 非整数输入会提示重新输入
  - 超出 1–100 范围的数字不会计入猜测次数
- 猜中后显示答案和总猜测次数
- 输入结束（EOF，例如在终端按 `Ctrl+D`／`Ctrl+Z`）时安全退出

## 环境要求

- Python 3.6 及以上（使用了 f-string）
- 仅依赖 Python 标准库，无需安装第三方包

## 运行方式

在 `first` 目录下执行：

```bash
python guess_number.py
```

如果系统同时安装了 Python 2 和 Python 3，可使用：

```bash
python3 guess_number.py
```

## 玩法示例

```text
欢迎来到猜数字游戏！
请输入一个 1-100 之间的数字：
50
大了，再试一次。
请输入一个 1-100 之间的数字：
25
小了，再试一次。
请输入一个 1-100 之间的数字：
37
猜中了！答案是 37，你一共猜了 3 次。
```

## 说明

- 猜测次数只统计 1–100 范围内的有效整数输入；无效输入和越界输入不计入次数。
- 每局仅进行一次游戏，猜中或退出后程序结束；如需再玩一局，重新运行即可。
